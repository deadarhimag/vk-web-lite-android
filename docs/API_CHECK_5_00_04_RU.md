# Замечания API и редактора — 5.00.04

Минимальная версия проекта — Android 8.0, API 26 (`app/build.gradle.kts`, `defaultConfig.minSdk = 26`). Сообщения о Normalizer (9), Cursor/Closeable (16), checkSelfPermission (23), removeIf (24) и более старых API не указывают на несовместимость с минимальным Android этого приложения. В переданной диагностике анализатор использует `current min is 1`, то есть не учитывает действующее значение модуля. Конкретную причину в пользовательском Android Studio без его журнала синхронизации установить нельзя.

## Исправлено в исходниках

- Шесть вспомогательных методов `MusicCache`, использующих MediaStore Downloads напрямую либо через другой helper, обозначены `@RequiresApi(Build.VERSION_CODES.Q)`: migrateToDownloads, readDownloads, findDownload, writeDownload, importFileToDownloads, deleteDownloads.
- Их корневые вызовы в rescan/publish/clear остаются защищены проверкой `SDK_INT >= Q`. На API 26–28 остаются прежние файловые ветки; minSdk не повышен до 29.
- В общем методе remove вместо `MediaStore.Downloads._ID` используется `MediaStore.MediaColumns._ID`. Для запроса одного общего столбца зависимость от Downloads не нужна.
- Исправлены комментарии с «недокачанное» и пробелом внутри кавычек. Сами шаблоны имён не менялись: пробел перед суффиксом (1) нужен для распознавания файлов MediaStore.
- Добавлена инструкция в README. Не добавлялись подавления NewApi, фиктивный API 1, дублирующий uses-sdk в исходный manifest или ненужный desugaring.

## Что сделать в Android Studio

1. Открыть папку `VkWeb`, содержащую settings.gradle.kts, а не отдельный Kotlin-файл или только папку app.
2. В Settings → Build, Execution, Deployment → Build Tools → Gradle выбрать JDK 17. Обычный Java 11 JRE не подходит для сборочной среды этого проекта.
3. Выполнить Sync Project with Gradle Files и устранить ошибки синхронизации. Убедиться, что app распознан как Android-модуль и установлен Android SDK Platform 35.
4. Запустить `:app:lintDebug`. Если после успешной синхронизации остаётся именно `current min is 1`, проверить, к какому модулю/копии проекта относятся сообщения; диагностике нужен журнал синхронизации и путь проблемного файла.

`minSdk` задаётся в Gradle и переносится в итоговый manifest при сборке. Добавление ещё одного uses-sdk только ради скрытия предупреждения IDE не исправляет импорт проекта. См. [Android Developers: Version your app](https://developer.android.com/studio/publish/versioning).

## Проверки и ограничения

Повторно проверен синтаксис 449 Kotlin-файлов по PSI, проверены вызовы Q-методов и XML. Изменения не затрагивают алгоритм отправки, разбор JS и правила очереди; прежний результат 109 изолированных JVM-тестов и 22 JS-регрессий относится к предыдущей функциональной проверке 5.00.03, а не к новому запуску полного набора.

Полноценный Android lint и APK в текущем окружении не подтверждены: доступен Java 11 JRE, отсутствует настроенный Android SDK. Синтаксическая проверка не доказывает отсутствие оставшихся замечаний lint и не заменяет Gradle-синхронизацию у пользователя.
